# Stack adapter — Astro 5 Content Layer

Binds the `wp-migration` portable core to an Astro 5 static site using the Content Layer API with a custom WordPress loader, Tailwind v4 and Netlify hosting.

Reference implementation: the IFS Coatings migration (WordPress/Oxygen → Astro 5), ~700 catalogue items across four content types plus 80 pages.

---

## Bindings

| Core placeholder | This stack |
|---|---|
| `<<CONTENT_DIR>>` | `content/` at the project root — **not** `src/content/`. Generated by the extractor; never hand-edited. |
| `<<LOADER_FILE>>` | `src/lib/loaders/wpContentLoader.ts` — a custom Content Layer loader |
| `<<URL_REWRITER>>` | `src/lib/urls.ts` → `rewriteInternalUrl()`, `isExternalUrl()` |
| `<<MEDIA_REWRITER>>` | `src/lib/mediaUrl.ts` → `rewriteMediaUrl()`, `rewriteMediaInHtml()` |
| `<<DOCUMENT_RESOLVER>>` | `src/lib/loaders/tdsLoader.ts` + `extractCode()` / `lookupTds()` |
| `<<REDIRECT_SOURCE>>` | `content/redirects.yml` |
| `<<HOST_REDIRECT_BINDING>>` | `netlify.toml` `[[redirects]]`, or `public/_redirects` |
| `<<REPORT_SCRIPTS>>` | `scripts/generate-product-csv.mjs`, `scripts/download-thumbnails.mjs` |

Collections are declared in `src/content/config.ts`. All share a `wpBase` schema (`title`, `slug`, `status`, `date`); custom post types extend `cptBase`, adding `post_type`, `featured_image` and a `custom_fields` object declared `.passthrough()` so unknown ACF meta survives while known keys stay typed.

## Stack-specific hazards

**A-RENDER-STALE — do not call `entry.render()` on extracted entries.** Astro's data-store singleton caches pre-rendered HTML and will serve stale output after content changes. Render bodies through an explicit `unified()` remark → rehype pipeline in the route file instead. This is the single most confusing failure in this stack: content on disk is correct, the built page is not.

**A-YAML-INDENT — the extractor's literal block scalars break `js-yaml`.** Bodies emitted under `body: |` sit at the wrong indent level on a minority of files. The loader patches indentation in memory before parsing. Any offline script reading the same files (report generators, CSV builders) must apply the identical patch — currently duplicated in `scripts/generate-product-csv.mjs`; factor it into a shared module when next touched.

**A-INTERNAL-HOSTS — sibling client domains count as internal.** `rewriteInternalUrl()` treats both `ifscoatings.com` and `polychemcoatings.com` as internal, because the two sites cross-link. When adding a site to the group, add its host here or its links will render as external.

**A-IMAGES-PLAIN — Astro's `<Image>` component is not configured.** Use plain `<img loading="lazy">`, and always pass `featured_image` through `rewriteMediaUrl()` first. Extracted media lives at `public/uploads/YYYY/MM/<file>` and is served from `/uploads/...`.

**A-TRAILING-SLASH — `trailingSlash: "always"`.** Every internal link and every redirect target must end with `/`, or the host issues an extra hop that costs link equity and shows up as a redirect chain in Search Console.

**A-FIELD-PREFIX — product fields use two naming conventions.** Prefer the vendor-prefixed key with the unprefixed one as fallback (`ifs_product_code` → `product_code`, `ifs_tds_url` → `tds`). Resolve through a helper, never inline.

## Body-location map

Write this table per project; it is not inferable from the file shape.

| Collection | Body source |
|---|---|
| `pages`, `posts` | Markdown body (builder JSON converted — text recovered, layout lost) |
| news CPT | `custom_fields.content` (raw HTML) |
| technical guides | `custom_fields["tech-guide-content"]` (raw HTML) |
| product / colour CPTs | No prose body — spec fields in `custom_fields` |

## Sparse-page gate

`isSparse` in `src/pages/[slug].astro` thresholds body length at 100 characters and renders a "being redesigned" placeholder. Track the set in `PAGES-TODO.md` until empty.

## Commands

```bash
npm run dev        # ask the user to run it — never start or stop the dev server
npm run build
npm run typecheck  # astro check + tsc --noEmit
npm run lint
npm run verify     # typecheck + lint — run before committing
```

TypeScript extends `astro/tsconfigs/strictest` with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`; indexed access returns `T | undefined`, so guard before use.
